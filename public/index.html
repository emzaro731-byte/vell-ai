Configuration checklist

If a service is unavailable, configure its secret in the Render service environment. Never put secret keys in this page.

GROQ_API_KEY
Required for AI generation and chat.
GITHUB_TOKEN
Required for project history, publishing, and APK workflow actions.
RENDER_API_KEY + RENDER_OWNER_ID
Required for creating and listing Render services.
SUPABASE_URL + SUPABASE_SERVICE_ROLE_KEY
Required only if using the current Supabase status integration. Keep service-role keys server-side.
